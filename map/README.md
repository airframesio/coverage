# Airframes Coverage Map

Next.js + deck.gl + MapLibre frontend for the Airframes coverage service. See the
[repository README](../README.md) for architecture, environment variables and deployment.

```bash
npm install
npm run dev            # http://localhost:3000
npm run lint
npm run typecheck
npm run build          # standalone server (Docker)
npm run build:static   # static export in out/ (Cloudflare Pages)
```
